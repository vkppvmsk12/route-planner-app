# AI Route Recommender — V1 Scope

## Goal

Build an app that recommends public transport routes
based on user preferences.

Users can:

- enter start location
- enter destination
- get 2–3 route options
- apply simple preferences:
  - fewer transfers
  - less walking
  - faster walking speed
- receive an AI explanation for recommendations

---

## What V1 DOES

- Public transport only
- Limited natural language preferences
- Route ranking
- AI explanation layer
- Simple Streamlit UI

---

## What V1 DOES NOT DO

- No live traffic
- No GPS navigation
- No accounts
- No route saving
- No voice assistant
- No chatbot
- No weather integration
- No real-time tracking

---

## Success Criteria

V1 is complete if:

1. User can input A → B
2. App returns routes
3. Preferences affect recommendation
4. AI explains tradeoffs
5. App works reliably
